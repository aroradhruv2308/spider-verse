title: How This Works
---

This doc lives in Spider-Verse/General-Concepts on Drive, so it publishes to the General Concepts section of the site automatically. The doc name becomes the page name.

Write notes as plain paragraphs like this. Bullet lists work too:

- point one
- point two

To make a new note anywhere: create a Google Doc inside the matching section folder (or a new subfolder inside one). The nightly sync finds it, converts it, and publishes it. Once a note is on the site, edit it in Obsidian - the sync never overwrites existing notes.
